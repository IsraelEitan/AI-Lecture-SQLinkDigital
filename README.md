# Working correctly with AI in development

A 30-minute talk in Hebrew for SQLink Digital's developers, as a single web page:
https://israeleitan.github.io/AI-Lecture-SQLinkDigital/

- `index.html` is the deck: one 1600 x 900 canvas, scaled to the window.
- `film.html` is the short film that slide 23 plays.

Keys: the arrows or a click move between slides; F full screen; B blank screen; a slide number then Enter jumps;
L laser pointer; Z zoom. The page loads its font (Rubik) from Google Fonts.
